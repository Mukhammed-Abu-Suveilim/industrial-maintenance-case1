# Тетради разведочного анализа данных

Новые тетради EDA кейса 1 хранить здесь с именами `01_<тема>.ipynb`, `02_<тема>.ipynb`. Модельные эксперименты находятся в [../experiments/](../experiments/README.md).

Основная тетрадь — [EDA-16-10.ipynb](EDA-16-10.ipynb), имя задано пользователем. Она объединяет основной EDA и материалы участников, выполнена в новом ядре и содержит результаты. Настройки — [eda_16_10.json](../../configs/eda_16_10.json); файлы запусков — `artifacts/eda/EDA-16-10/runs/` от корня проекта. Все нецелевые поля доступны по допущению пользователя от 2026-10-16; неизвестные определения и состав конкретных моделей остаются открытыми.

Перед созданием или изменением тетради применять [стандарт кода и экспериментов](../../CODING_STANDARDS.md). Корень проекта для этого каталога — `../..`; использовать его `.venv` и конфигурацию из `configs/`.

[Исходная тетрадь EDA](../01_eda.ipynb) и [материалы участников](../../TEAM_EDA_FINDINGS.md) сохраняются по прежним путям как источники объединённой работы.
