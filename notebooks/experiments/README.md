# Тетради модельных экспериментов

Одна модель — одна тетрадь. Настройка, варианты входов, диагностика
и выбор порога находятся в тетради соответствующей модели.

- [01_logistic_regression.ipynb](01_logistic_regression.ipynb): числовые,
  табличные входы и TF-IDF; 66 обучений в сохранённом запуске.
- [02_random_forest.ipynb](02_random_forest.ipynb): 64 обучения,
  четыре выбранные модели, два F2-объекта.
- [03_catboost.ipynb](03_catboost.ipynb): 64 обучения,
  четыре выбранные модели, два F2-объекта.
- [04_rubert_tiny2.ipynb](04_rubert_tiny2.ipynb): текстовый трансформер B,
  выполнены исходные два обучения и четыре обучения дополнительных seed;
  проверены синтетические переформулировки. Результаты и ограничения ниже.

Сопоставление выполненных опытов с полным заданием —
[REQUIREMENTS_AUDIT.md](../../REQUIREMENTS_AUDIT.md). A/B оценены на
validation; C, LLM/RAG и итоговая test-оценка этим этапом не закрыты.

Завершённый анализ A/B — [AB_RESULTS.md](AB_RESULTS.md),
30 разобранных ошибок — [AB_ERROR_ANALYSIS.md](AB_ERROR_ANALYSIS.md),
передача участнику C/LLM/RAG — [AB_HANDOFF.md](AB_HANDOFF.md).
Самостоятельные разделы `ab-review` читают сохранённые результаты;
их можно выполнить в свежем ядре через `scripts/check_eda.py --tag ab-review`.
Общий разбор в тетради B использует тег `ab-summary`. Полный Run All
исходных тетрадей может запускать обучение; для этой проверки он
не выполнялся. Дополнительных исследовательских fit нет.

Передаваемый [ZIP A/B](../../artifacts/experiments/ab_review_20261018T122826_185163Z/ab_handoff.zip)
содержит шесть моделей, train/validation и отдельные метки, но не test.
Копии моделей проверены локально по вероятностям и меткам.
Пройдены 54 синтетических теста; прежние 2 056 файлов результатов
сохранены по SHA-256. Проверка набора из корня:
`uv run --no-sync python scripts/check_ab_review.py`.

Первые три тетради выполнены в свежих ядрах `.venv` Python 3.11.9.
В Random Forest финальное выполнение повторно использует 64 готовых
обучения через явно заданный reuse_fitted_batch: исправлено округление
вероятностей при параллельном суммировании деревьев. Обучение —
шесть потоков, применение — один. Первый проход сохранён в initial_parallel/;
дополнительных fit нет. Для нового обучения задать reuse_fitted_batch=null,
после сообщения пользователю конфигурации и бюджета.

## Входы и оценивание

A_numeric: operating_hours, temperature_c, vibration_mm_s,
pressure_bar, load_ratio. A_tabular_restricted: те же измерения,
horizon_days, equipment, manual_id. T0_tfidf: только operator_log,
в тетради логистической регрессии. required_route, severity, id
и обе цели исключены из входов; severity допустима для диагностики.

Используется eda_v1: train 10 655, validation 2 193, test 2 152.
Предобработка и модели обучаются только на train. Конфигурация выбирается
по AP отказа и macro-F1 диагноза; затем для отказа выбирается F2-порог.
Диагноз независим от отказа, включает normal. Для моделей деревьев
добавлены диагностические точки максимальной полноты при precision
не ниже 70%/80%, включая явный статус недостижимости.

128 новых обучений двух семейств и 128 записей MLflow завершены.
Выполнены 36 парных групповых сравнений по 2 000 повторов, seed 42.
Старые модели и частотные контроли не переобучались.

- random_forest / `failure_within_30d` / `A_numeric`: average_precision **0.778035**.
- random_forest / `failure_within_30d` / `A_tabular_restricted`: average_precision **0.776655**.
- random_forest / `fault_type` / `A_numeric`: macro_f1 **0.770903**.
- random_forest / `fault_type` / `A_tabular_restricted`: macro_f1 **0.772661**.
- catboost / `failure_within_30d` / `A_numeric`: average_precision **0.786742**.
- catboost / `failure_within_30d` / `A_tabular_restricted`: average_precision **0.783998**.
- catboost / `fault_type` / `A_numeric`: macro_f1 **0.757161**.
- catboost / `fault_type` / `A_tabular_restricted`: macro_f1 **0.773016**.

Точные параметры, F2-пороги, метрики и ограничения:
[Random Forest](../../artifacts/experiments/random_forest_20261017T203223_834932Z/summary.md),
[CatBoost](../../artifacts/experiments/catboost_20261017T203913_936394Z/summary.md).

## Воспроизводимость

Конфигурации хранятся в configs; зависимости — pyproject.toml и uv.lock.
CatBoost 1.2.10 установлен через uv. Модели, исходные прогнозы при 0,5,
пороговые объекты, F2-прогнозы, графики и журналы сохранены в новых
каталогах результатов. Пройдены 36 тестов и Ruff затронутых файлов;
195 прежних нарушений стиля в других файлах сохраняются.
Проверены SHA-256 1547 прежних файлов: изменений нет.
Тестовых прогнозов и метрик нет.

Конфигурации и пороги выбраны на одной validation: оценки и интервалы
могут быть оптимистичными и не заменяют итоговую тестовую оценку.
Повторяемость текстовых шаблонов ограничивает интерпретацию текстового
контроля. Числовые метрики не доказывают причинного влияния признаков.
Авторство остальных участников требует подтверждения; этот этап
реализован агентом по решениям пользователя.

Запуск из корня проекта:

```powershell
$env:UV_CACHE_DIR = Join-Path $PWD '.cache/uv'
uv sync
uv run --no-sync python scripts/check_eda.py notebooks/experiments/02_random_forest.ipynb --timeout 1800
uv run --no-sync python scripts/check_eda.py notebooks/experiments/03_catboost.ipynb --timeout 1800
```

Рабочий каталог каждой тетради — notebooks/experiments, корень — `../..`.
Перед правкой применять [CODING_STANDARDS.md](../../CODING_STANDARDS.md),
перед следующим опытом читать актуальное состояние в
[PROJECT.md](../../PROJECT.md) и сообщать пользователю настройки.

## RuBERT-tiny2: полный CPU-опыт

Только operator_log, две независимые цели. Фиксированы learning_rate=0.00005,
пять эпох, batch=32/64, max_length=128, FP32, seed=42. Лучшие эпохи —
по validation AP/macro-F1, затем F2-порог отказа. Все 11 кодовых ячеек
выполнены в свежем ядре .venv на CPU; два обучения и две завершённые
записи MLflow, девять сравнений по 2 000 групповых повторов.
Test не оценивался, контроли не переобучались.

Результат: `rubert_tiny2_20261018T111625_114468Z`;
[сводка](../../artifacts/experiments/rubert_tiny2_20261018T111625_114468Z/summary.md).
Validation AP **0,450304**, macro-F1 диагноза **1,0**. По F2 выбран
порог **0,130998**: precision **0,371429**, recall **0,895317**,
F2 **0,698324**. Обучение заняло **199,48 / 201,27 с** на две цели.
Разность AP против TF-IDF **+0,008111**, групповой 95%-й интервал
**[-0,012195; 0,028519]**. Преимущества над TF-IDF не установлено.
Шесть шаблонов ограничивают выводы о новых формулировках; оценки
после выбора эпохи и порога на той же validation могут быть оптимистичными.

В начале тетради DEVICE=cpu либо cuda; автоматической подмены нет.
CPU: `uv sync --locked --extra transformer`.
NVIDIA: `uv sync --locked --extra transformer-cuda`.
Пройдены 46 тестов и Ruff изменённых файлов. Сохранены все checkpoints,
выбранные модели, токенизатор, прогнозы с id, диагностика и исходный код.
Перенос на GPU текущей версии ещё не проверен; инструкция и состав
переносимого ZIP — [TRANSFORMER_SERVER.md](../../TRANSFORMER_SERVER.md).
Эта запись относится к исходному seed 42; актуальные проверки ниже.
