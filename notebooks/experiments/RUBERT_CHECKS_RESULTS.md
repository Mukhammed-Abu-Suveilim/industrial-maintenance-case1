## Проверка формулировок

Вывод: идеальный диагноз на исходной validation не переносится на
новые формулировки столь же надёжно. Два seed RuBERT дают 22/24 верных
ответа, seed 17 — 17/24 против 18/24 у TF-IDF. Преимущество трансформера
на этой небольшой диагностике зависит от seed; выбирать лучший seed
по этим 24 текстам не следует. Варианты одного источника зависимы.

24 синтетические переформулировки шести наблюдений validation, по четыре варианта на класс. Пользователь подтвердил сохранение смысла всех 24 примеров до расчёта прогнозов. Ни эпохи, ни seed, ни пороги по этому набору не подбирались.

- tfidf, диагноз: исходные тексты accuracy=1.000000; переформулировки accuracy=0.750000, macro-F1=0.761544; решение изменилось в 6/24 парах.
- rubert_42, диагноз: исходные тексты accuracy=1.000000; переформулировки accuracy=0.916667, macro-F1=0.919048; решение изменилось в 2/24 парах.
- rubert_17, диагноз: исходные тексты accuracy=1.000000; переформулировки accuracy=0.708333, macro-F1=0.686905; решение изменилось в 7/24 парах.
- rubert_123, диагноз: исходные тексты accuracy=1.000000; переформулировки accuracy=0.916667, macro-F1=0.916005; решение изменилось в 2/24 парах.

Отказ: только изменение прогнозов, без эталонных меток:

- tfidf: среднее |Δp|=0.094921, максимум 0.230232; изменений решения при сохранённом F2-пороге: 6/24.
- rubert_42: среднее |Δp|=0.119304, максимум 0.256256; изменений решения при сохранённом F2-пороге: 11/24.
- rubert_17: среднее |Δp|=0.132284, максимум 0.257013; изменений решения при сохранённом F2-пороге: 8/24.

Это небольшая целевая диагностика, а не оценка качества на новом наборе данных. Варианты одного источника зависимы. Метки диагноза наследуются от сгенерированных данных; экспертная диагностика оборудования не проводилась. Меток отказа для переформулировок нет: AP, ROC-AUC, precision/recall/F2 отказа на синтетике не вычислялись. Разность вероятностей не доказывает ошибку прогноза риска или причинный эффект формулировки.

Реализация и первоначальная проверка текста выполнены агентом; смысл переформулировок проверен пользователем.
